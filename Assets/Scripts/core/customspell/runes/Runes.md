Крафт заклинаний с помощью глифов. Каждый глиф имеет уникальный эффект, который можно комбинировать с другими глифами
для создания мощных заклинаний.
Добавление глифов включает соответствующие свойства заклинания или увеличивает их значение, если глиф уже присутствует в
заклинании.
Некоторые глифы могут быть несовместимы друг с другом, что ограничивает возможности их комбинации. Например, глиф "
Огонь" может быть несовместим с глифом "Лёд", что делает невозможным их совместное использование в одной связке.
Глифы различаются по типам: Ядро, Свойство, Движение, Триггер. Разные типы глифов выглядят по разному.
Сетка поля в виде гексагона определенного радиуса. Глифы могут иметь различную форму и размер.
Соединение глифов происходит при соприкосновении сторон, каждая сторона каждого гекса (кроме внутренних) глифа является
условным входом, но одна стороная является выходом.
Запрещены циклические соединения глифов, то есть нельзя соединять глифы так, чтобы они образовывали замкнутый контур.

Взаимодействие на доске:

* Чтобы **взять** глиф, нужно кликнуть по нему левой кнопкой мыши и удерживать кнопку нажатой.
* Чтобы отпустить глиф, нужно отпустить левую кнопку мыши.
* Чтобы повернуть глиф, нужно **взять** его и кликнуть правой кнопкой мыши.
* Глифы можно перетаскивать по полю, но нельзя накладывать друг на друга.
* Глифы можно соединять друг с другом, если их стороны соприкасаются.
* Глифы можно поворачивать на 60 градусов, поворот осуществляется вокруг оси гекса за который его держит мышь.
* Можно выделять Глифы чтобы взаимодействовать со всей группой, например, перемещать, вращать или удалять их.
* При неверном позиционировании Глиф возвращается в прошлое положение.
* Доступна отмена действий через комбинацию клавиш Ctrl+Z, а также повтор действий через Ctrl+Y.

Редактор заклинаний (в игре):

* Позволяет создавать заклинания путем размещения глифов на поле.
* Состоит из двух частей: поле для размещения глифов и панель с доступными глифами.
* Отображает визуальное представление заклинания и его свойства.
* Подсвечивает несовместимые глифы и запрещает их соединение.
* Отображает итоговую стоимость в ArcanePower и затраты маны.
* Позволяет задать имя заклинания и сохранить его в базу данных.
* Хранятся только глифы и их положения, а свойства заклинания формируются на основе этих глифов.
* Должна быть поддержка версионирования, удаление глифов которые не проходят актуальную валидацию.

Редактор глифов:

* Инструмент разработчика для создания внешнего вида отдельного глифа и задания его свойств.
* Позволяет задать форму (любую произвольную по сетке), размер, цвет, текстуру и другие визуальные характеристики глифа.
* Свойства определяются через ScriptableObject котрый получает общий контекст заклинания и изменяет его свойства.
* Созданные глифы сохраняются в базу данных и могут быть использованы в игре.

## Стихии

* ОГОНЬ - горение
* ЛЁД - стаки заморозки (+замедление) потом фриз
* ЯД - стаки увелич вход урон + долгий и медленный дот
* ВОЗДУХ - базовое отталкивание + увеличение отталкивания + ускорение для союзников/замедление снарядов
* ЗЕМЛЯ - дает армор/цель короче прыгает и слабее отталкивается
* ТЬМА - слепота/урезание урона
* ЭЛЕКТРИЧЕСТВО - короткое замедление/процентный урон/дот при движении/автонаводка
* СИЛА - непроходимое/Уничтожение вражеских снарядов
* МОРОЗ - замедление/отключение регена хп + урон по мане
* МАГИЯ - -манакост/

идеи эффектов:
* вол хак
* рут
* слип
* бкб
* сайленс
* окаменение
